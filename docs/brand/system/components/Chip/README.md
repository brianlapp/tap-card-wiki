# Chip

A tappable suggestion that adds a prompt or detail, such as "+ An inside joke" under the studio prompt box.

`m-chip`: `paper` fill, 2px `ink` outline, `radius-pill`, 14px bold text. Hover turns it `butter`. Start the label with "+" when it adds something. Lay chips out in a wrapping row with an 8px gap (`space-2`).
