# SceneFrame

One scene of an uncard shown as a filmstrip frame: number, short name, illustration and a one-line caption. Use frames in an `m-strip` to show a card's sequence.

`m-frame` is a `paper` frame with an illustration on a soft tint (`bg-sky-soft`, `bg-butter`, `bg-mint-soft`, `bg-bubblegum-soft`). The name is the display face in capitals, about two words; the caption is one short sentence. Illustrations come from the **Illustrations** assets.
