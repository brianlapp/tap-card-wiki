# Button

Three buttons: main (Tomato), dark (Ink) and ghost. Use one main button per view, for the thing the page is for.

- **Main** (`m-btn m-btn--red`): `tomato` fill, `ink` text, 2.5px `ink` outline, `radius-button`, `shadow-button`. Label "Make one" wherever the action creates an uncard.
- **Dark** (`m-btn m-btn--ink`): secondary actions such as "Play Riley's uncard".
- **Ghost** (`m-btn m-btn--ghost`): low-emphasis actions such as "Try another direction".
- **Small** (`m-btn--sm`): add to any variant in dense rows and emails.

Labels are verbs in sentence case, no exclamation marks. Hover lifts by 1px; pressed moves 2px down and right and the shadow shrinks to 1px. Focus shows the 3px `focus-ring` outline. On an `ink` section, give the main button a `marquee` outline and shadow.
