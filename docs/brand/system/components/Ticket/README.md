# Ticket

The brand's ticket motif, with notched sides, for prices, recipient name tags and "admit one" moments.

`m-ticket`: `paper` (or `m-ticket--red` for `tomato`) with a 2.5px `ink` outline. The small line is `label-13`-style caps; the big line is the display face. Content: a short label ("ADMIT ONE", "PER UNCARD") and one name or number ("RILEY · 9", "ONE PERSON"). A ticket can be rotated a few degrees as a sticker, once per view.
