# Headline

The display headline with its Tomato full stop: the brand's signature device.

Set the text in a `display-*` style (Archivo Condensed Black, sentence case, leading 0.92) in `ink`, and wrap each sentence-ending full stop in `<span class="dot">.</span>` so it renders in `tomato`. One or two short sentences; no exclamation marks. On an `ink` section the text turns `paper` and the stop stays `tomato`.
