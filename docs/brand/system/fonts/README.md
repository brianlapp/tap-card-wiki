# Fonts

All three files are Archivo by Omnibus-Type, licensed under the SIL Open Font License 1.1 (see `OFL.txt`). You may use, embed and share them freely, but not sell the fonts on their own.

| File | Family name | What it is | Use |
| --- | --- | --- | --- |
| `Archivo-Variable.woff2` | Archivo | The variable font: weights 100 to 900, widths 62 to 125 | Body text (`text` family) |
| `ArchivoCondensed-Variable.woff2` | Archivo Condensed | Archivo at width 62, renamed | Headlines (`display` family), weight 900 |
| `ArchivoSemiExpanded-Variable.woff2` | Archivo SemiExpanded | Archivo at width 112.5, renamed | Labels (`label` family), weight 800, capitals |

For desktop apps (Keynote, PowerPoint, Figma), install Archivo from Google Fonts (https://fonts.google.com/specimen/Archivo) and use Archivo Black or a condensed width for headlines. The web files above load through `tokens/tokens.css`.
