# Illustrations

The brand's flat objects, drawn with a 2.5-unit `ink` outline, a small hard shadow and five colours at most. Use them as objects in marketing, scene frames and empty states. Never add faces, and never replace them with stock photos.

- `uncard-cake.svg`, `uncard-gift.svg`, `uncard-balloons.svg`, `uncard-confetti.svg`: celebration.
- `uncard-rocket.svg`, `uncard-star.svg`: adventure and games.
- `uncard-envelope.svg`, `uncard-card.svg`: giving and sharing.
- `uncard-cassette.svg`: music and songs.
