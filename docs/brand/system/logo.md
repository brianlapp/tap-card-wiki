# Logo

The wordmark is the logo. There is no symbol, badge or mascot next to the name. The name, set well, is the whole logo.

## The wordmark

- **Typeface:** Archivo, outlined (converted to shapes, never live text).
- **Width and weight:** Expanded 112, Black 900.
- **Tracking:** −12/1000.
- **The full stop:** Tomato, tucked 10 units in. Every version ends in it. It is the same full stop that closes our headlines on screen: this is certain, this is for you.
- **Clear space:** half the cap height on every side.
- **Minimum size:** 96px wide on screen, 24mm in print.

The **stacked** version (UN over CARD.) is for square spaces such as posters and social avatars. Same letters, same full stop, two lines.

## Please don't

- Never pair it with an icon or symbol.
- Never recolour the full stop.
- Never stretch or squash it.
- No outlines, shadows or effects.
- Never retype it in another font.
- Never place it on a busy background.
